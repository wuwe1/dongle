## Arduino UNO R3 套件（OpenJumper，带 Sensor Shield V2.3），按总线分

| 总线 / 操作 | 器件 |
|---|---|
| GPIO 输入 | 按钮模块、触摸模块、PIR 人体感应（HC-SR501）、散装按键 |
| GPIO 输出 | LED、继电器模块（5V，**不接市电**）、蜂鸣器、单位数码管 |
| ADC | 10K 电位器、光敏电阻、声音传感器、MQ 系列气体传感器（5V 加热，耗电、会发烫） |
| PWM | SG90 舵机、蜂鸣器 |
| 红外 | 红外接收模块、散装红外接收头、21 键 NEC 遥控器（**没有发射管**） |
| 单总线 | DHT11 温湿度 |
| 类 SPI | 74HC595 移位寄存器 |
| 并口 | LCD1602（没有 I2C 转接板） |
| 其他 | HC-SR04 超声波（Echo 是 5V，接 ESP32 要分压）、130 直流电机加风扇叶、电阻 220Ω/1K/10K |
| **I2C** | **没有** |

UNO 是 5V 电平，ESP32-S3 是 3.3V。套件模块接到 ESP32 时，能用 3.3V 供电的就用 3.3V 供电，拿不准的先量输出电压。

## 要买

- [ ] ESP32-S3 开发板 ×2（N16R8）。最好选两个 Type-C 口（USB + COM）的；只有一个口、且经过 CH34x 串口芯片转的，
      要把 `firmware/sdkconfig.defaults` 里的 console 改成 UART
- [ ] **BME280**（I2C，0x76/0x77；读 ID 寄存器 0xD0：0x60 是 BME280，0x58 是 BMP280，可以拿来鉴别假货）
- [ ] **SSD1306 0.96 寸 OLED**（I2C，0x3C）
- [ ] 可选：PCF8574 转接板，把 LCD1602 变成 I2C 设备（0x27 / 0x3F）
- [ ] 940nm 红外发射 LED 几个，加 S8050 三极管（控制空调、电视）
- [ ] 逻辑分析仪（24MHz 8 通道，Saleae 兼容款，配 PulseView）
- [ ] USB 转 TTL（CH340/CP2102，能切 3.3V），接路由器调试口
- [ ] 面包板、杜邦线（公对公、公对母）
- [ ] 可选：WS2812 灯带、一台旧路由器、焊锡丝、助焊剂、吸锡带
