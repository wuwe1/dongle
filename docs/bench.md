## Arduino UNO R3 套件（OpenJumper，带 Sensor Shield V2.3），按总线分

| 总线 / 操作 | 器件 |
|---|---|
| GPIO 输入 | 按钮模块、触摸模块、PIR 人体感应（HC-SR501）、散装按键 |
| GPIO 输出 | LED、继电器模块（5V，**不接市电**）、蜂鸣器、单位数码管 |
| ADC | 10K 电位器、光敏电阻、声音传感器、MQ 系列气体传感器（5V 加热，耗电、会发烫） |
| PWM | SG90 舵机、蜂鸣器 |
| 红外 | 红外接收模块、散装红外接收头、21 键 NEC 遥控器（**没有发射管**） |
| 单总线 | DHT11 温湿度 |
| 类 SPI | 74HC595 移位寄存器 |
| 并口 | LCD1602（没有 I2C 转接板） |
| 其他 | HC-SR04 超声波（Echo 是 5V，接 ESP32 要分压）、130 直流电机加风扇叶、电阻 220Ω/1K/10K |
| **I2C** | **没有** |

UNO 是 5V 电平，ESP32-S3 是 3.3V。套件模块接到 ESP32 时，能用 3.3V 供电的就用 3.3V 供电，拿不准的先量输出电压。

## 要买

第一批（都已买）：

- [x] **ESP32-S3-DEV-KIT-N16R8-M**（已买；WROOM-1 N16R8 模组，排针已焊，板载天线）。只有一个 Type-C 口，旁边有
      CH343（USB 转串口），应该还带一颗 USB 集线器芯片，所以一个口同时有串口和原生 USB。到货后在电脑上看看
      出现几个设备；如果只有串口，就把 `firmware/sdkconfig.defaults` 的 console 改成 UART。板上标 RGB 的灯
      多半是一颗可编程彩灯（WS2812 类），引脚号按板子的资料核对
- [x] **AHT20 + BMP280 组合板**（已买；一块板两颗 I2C 芯片：AHT20 温湿度在 0x38，BMP280 气压在 0x77 或 0x76，
      以 scan 为准；BMP280 的 ID 寄存器 0xD0 = 0x58。排针如果没焊，就是第一次焊接练习）
- [x] **逻辑分析仪**（已买）：24MHz 8 通道、Saleae 兼容款，详情页写着支持 PulseView/sigrok，输入不超过 5V
- [x] **0.96 寸 OLED**（已买：4 针 I2C，0x3C，白色，带稳压（3.3V 和 5V 都能接），排针已焊。"新款"驱动芯片可能是
      SSD1315，基本兼容 SSD1306 的库）。跟组合板挂在同一对线上，总线上就有三个设备
